How to export your tickets from HubSpot

  1. In HubSpot, go to CRM > Tickets and switch to the table view (the list icon at the top).
  2. Click Edit columns and make sure the table shows your time property (for example "Time spent"), Create date, Ticket owner and the associated Company.
  3. Use the filters to limit the tickets, for example by create date for last month.
  4. Click Export (in the table's toolbar, or under Actions in some accounts). Choose CSV as the file format and confirm. HubSpot emails you a download link.
  5. Open the email, download the file, unzip it if it's zipped, and drop the .csv on this page.

Menu names change from time to time. If a step looks different in your account, see HubSpot's own help on exporting records.
